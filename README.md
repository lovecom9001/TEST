# PDF 편집기

React + TypeScript + Vite로 만든 웹 기반 PDF 편집기입니다.

## 기능

- ✅ PDF 파일 업로드 및 보기
- ✅ 텍스트 추가
- ✅ 이미지 추가
- ✅ 도형 그리기 (사각형, 원)
- ✅ 서명 추가
- ✅ 페이지 순서 변경
- ✅ 편집된 PDF 다운로드
- ✅ 반응형 디자인

## 시작하기

### 설치

```bash
npm install
```

### 개발 서버 실행

```bash
npm run dev
```

### 빌드

```bash
npm run build
```

### 프리뷰

```bash
npm run preview
```

## 기술 스택

- React 18
- TypeScript
- Vite
- Tailwind CSS
- PDF.js
- Lucide React (아이콘)

## 사용 방법

1. **PDF 업로드**: "PDF 파일 선택" 버튼을 클릭하여 PDF 파일을 업로드합니다.
2. **도구 선택**: 왼쪽 사이드바에서 원하는 편집 도구를 선택합니다.
3. **편집**: PDF 페이지 위에 텍스트, 이미지, 도형, 서명을 추가합니다.
4. **다운로드**: "편집된 PDF 다운로드" 버튼을 클릭하여 저장합니다.
